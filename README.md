## 双ISP原生住宅IP到底是什么，为什么越南TikTok非它不可

先把概念拆开。“住宅IP”说的是这个地址在 IP 数据库里被归类为家庭宽带用户，不是数据中心出口；“双ISP”指的是它在 ping0、scamalytics、IPinfo 这类平台上，同时被识别为住宅用户 IP 和 ISP 类型 IP。两者叠加，效果就是让平台看到一个“越南本地家庭在上网”的网络特征。

TikTok、Shopee、Facebook 这类平台的风控并不看你 CPU 几核，它看的是这个 IP 像不像真实用户。机房 IP 的 ASN 归属是 IDC，行为模式是服务器，平台一眼就能分类；住宅 IP 的 ASN 挂在宽带运营商名下，和普通越南用户混在一起，识别成本高得多。做越南区账号养护、直播带货、多账号矩阵的人，花钱买的其实就是这层身份。

问题在于，市面上不少标着“越南家宽 IP”的产品，实际只是 IDC IP 或者广播 IP，宣传页写得像住宅，一查 ASN 就露馅。买之前值得自己核一遍四件事：

- **ASN 归属**：是运营商还是数据中心；
- **ISP 信息**：IPinfo 的 Company 字段显示的是 ISP 还是 Hosting；
- **IP 类型识别结果**：ping0 这类工具给的是住宅还是机房；
- **风控数据库记录**：scamalytics 的欺诈分值高不高。

这四项里任何一项对不上，“原生住宅”就要打个问号。

## FAQ

**IP 是真住宅吗？**
第三方测评显示 ASN 为 AS7602 西贡邮电，ping0 判定住宅属性，scamalytics 欺诈值 0。拿到机器后建议自己再查一遍 ASN 和 IP 类型。

**国内能直连吗？**
能连，体验分运营商。移动约 96ms 比较顺，电信约 210ms 可用，联通约 270ms 建议中转。

**联通用户怎么办？**
配香港或新加坡中转节点，同时开 BBR。这是官网自己也建议的方案。

**能装 Windows 吗？**
可以，但需要提交工单由官方协助安装，不能自助选择。

**年付能退款吗？**
VPS 类产品支持 48 小时内不满意无条件退款；VDS 类只退网站余额，购买前看清产品类型。

**每台给几个 IP？**
1 个双 ISP 住宅 IPv4，加 5 个免费原生越南 IPv6。

**跑 TikTok 效果怎么样？**
第三方测评称移动网络下直播表现较好，这与 IP 的住宅属性直接相关。但效果还取决于账号历史、操作方式和中转质量，IP 只是其中一环。

**流量跑满会被限速吗？**
丽萨的资料里没有给出带宽滥用条款。不限流量套餐的实际体验仍受 100Mbps 或 200Mbps 端口带宽约束，别把它理解成“无限带宽”。
